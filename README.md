# Bluetooth Controlled RC Car

## 📌 Project Description

The Bluetooth Controlled RC Car is a wireless robotic vehicle designed to
demonstrate Bluetooth communication, microcontroller programming, and
motor control. The car is controlled remotely using a smartphone through
an HC-05 Bluetooth module connected to an Arduino microcontroller.

The Arduino receives movement commands wirelessly and controls the DC
motors through an L298N motor driver, allowing the car to move forward,
backward, left, and right.

## ⚙️ Key Features

- 📱 Wireless smartphone control
- 🔵 HC-05 Bluetooth communication
- 🚗 Forward and backward movement
- ↔️ Left and right directional control
- ⚡ DC motor control using L298N
- 💻 Arduino-based embedded programming

## 🔧 Components Used

- Arduino
- HC-05 Bluetooth Module
- L298N Motor Driver
- DC Motors
- Robot Car Chassis
- Battery
- Jumper Wires

## 🛠️ Technologies Used

- Embedded C / Arduino C
- Bluetooth Communication
- Microcontroller Programming
- Motor Control

## 🎯 Project Objective

To design and develop a wireless RC vehicle that can be controlled
through Bluetooth commands from a smartphone and demonstrate
microcontroller-based motor control.
